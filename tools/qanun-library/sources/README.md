# Original-source audit

Run `python -u tools/qanun-library/sources/audit_sources.py` from the repository root for the complete local-original comparison. Add `--online --retry-only` to retrieve originals still missing from the local archive. Caches are resumable and excluded from Git and public output. A source notice is never a verified law.

The audit normalizes extraction whitespace, Unicode compatibility forms and typographic quotation-mark equivalents. Only complete normalized text equality passes automatically. A high token-similarity score does not pass. Every material difference remains unresolved with a difference file, and a source identity inferred only from metadata titles requires the title to be located in the original.

`verify-sources.mjs` checks every current reading edition, hashes the identified original files again and fails when any law lacks supported original-source reading. Its states remain separate: exact original transcription/character sequence; a distinct complete original-derived reading that repairs an earlier truncated or defective extraction; an independently visually collated reading; or a complete original facsimile whose full page pixels are independently re-rendered and compared. A source-image reading does not certify the old OCR. Notices are not counted as source-verified laws. None of these checks establishes current force, later amendment completeness or a legal interpretation.

The local source audit and acquisition/selection reports contain archive paths and remain ignored alongside the original caches. The public-safe current-reading register is generated by the driver as `tools/qanun-library/source-status.json`. Hosted builds use that sanitized register and committed reading artifacts, never private source-cache paths.

`build_reading_inputs.py` creates the committed `reading-inputs.json.gz` bundle and its hash/coverage summary. `reading-inputs.mjs` exports `getSourceReadingInput(record, expectedOriginalSha256)`. It returns no input for a different text version, rejects a supplied original hash mismatch, and admits layout only when every literal non-whitespace character equals the effective record. The original PDF's paragraph and word spacing can therefore repair fragmented presentation without changing legal characters or historical record IDs. The existing dedicated fallback-layout and original-facsimile readers take precedence where appropriate.

`finish_local_sources.py` documents the exact146-page BRA consolidation behind the held Balochistan text, the DRS695/1887 Marriage Functions original and the selected59-page Representation of the People Act in the official281-page ECP volume. The older84-page Balochistan edition and35-page original1977 Representation Gazette are not silently treated as the separately held amended compilations.
